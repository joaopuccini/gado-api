# Wave 04 Herd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Entregar raças, lotes e animais com paridade funcional do legado, contrato HTTP camelCase, autorização por fazenda, persistência transacional e consumo tipado no `gado-app`, encerrando o Gate `G3-herd`.

**Architecture:** Substituir os serviços genéricos legados por módulos hexagonais. Controllers Nest traduzem HTTP e delegam para UseCases sem framework; ports descrevem persistência; adapters Prisma obtêm `farmId`, `localUserId` e schema exclusivamente do contexto validado. Raças pertencem ao tenant, lotes e animais pertencem à fazenda selecionada. A compra de animal e o lançamento de caixa usam uma única transação Prisma.

**Tech Stack:** NestJS 11, TypeScript, Prisma 7/PostgreSQL, Jest, OpenAPI/Swagger, React 19, Vite, Vitest, Testing Library, `openapi-typescript`.

**Safety invariants:** Nunca aceitar tenant, schema, organização ou fazenda do body/query/path. Nunca usar `prisma db push`, `migrate reset` ou banco não descartável. Testes de migration/isolation criam banco filho `gado_wave00_test_<12hex>` a partir de `DATABASE_URL`, verificam o nome e removem o banco ao final. Cada comportamento nasce em commit RED e recebe commit GREEN separado.
